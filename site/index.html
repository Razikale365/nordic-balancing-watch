When Nordic balancing prices appear, and how often they change

The APIs of eSett, ENTSO-E and the Nordic TSOs only return a price as it is now. This site polls them every 15 minutes and keeps every version, so the first publication time and every later revision are on record.

    Method

    How it is measured

    First publication

    A price counts as published at the first poll that returns it with a value. Rows that appear without a price are not yet published.

    Imbalance prices are polled every 15 minutes, reserve capacity hourly, so times are accurate to about one poll.

    What is not counted

    Values already on record when collection started, or that first appeared after a collector outage, have no reliable publication time. They are left out of delays and of the share revised.

    Revisions

    Any change to a published value is a revision, and so is a value that disappears. The log keeps the previous and the new price. Nothing is smoothed or corrected.

    Know when a price changes

    Planned for those who settle, trade or model against these prices:

    • Alerts when a published price is revised
    • An API with the full history of every version
    • Bulk export for backtests that use only what was known at the time

    Used only to tell you when alerts and the API launch. No tracking, no cookies. Ask to be removed at any time.
